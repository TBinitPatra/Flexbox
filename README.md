# Flexbox Puzzle

A small interactive web game that helps learners practice CSS Flexbox by completing level-based layout challenges.

## About the project

This project teaches core Flexbox concepts such as:

- `flex-direction`
- `justify-content`
- `align-items`
- `flex-wrap`

Players are shown a target layout and must write the correct CSS rule to match it.

## Features

- Beginner-friendly Flexbox practice
- Multiple levels with increasing difficulty
- Visual feedback for correct answers
- Simple static HTML/CSS/JavaScript setup

## Project structure

- `front_page/` – landing page and intro UI
- `level_page/` – game logic, level data, and gameplay UI
- `README.md` – project overview and usage instructions

## Run locally

1. Open the project folder in your browser.
2. Start by opening `front_page/index.html` for the landing page.
3. From there, open the game page or the level screen in the browser to begin playing.


Then visit:

```text
http://localhost:8000/front_page/index.html
```
